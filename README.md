\# DetectDefend

\## Machine Learning Network Attack Detection and Defence System



DetectDefend is a machine-learning-based cybersecurity project designed to classify network traffic as normal or malicious, simulate adversarial attacks, improve model robustness through defensive retraining, and explain predictions using SHAP.



\### Key Features

\- Network attack detection using XGBoost.

\- Adversarial attack simulation.

\- Defensive retraining and robustness evaluation.

\- SHAP-based feature importance and explainability.

\- Flask web dashboard.

\- Network traffic dataset evaluation using UNSW-NB15 and NSL-KDD.



\### Technologies

Python, XGBoost, Pandas, NumPy, Scikit-learn, SHAP, Flask, HTML, CSS, JavaScript and Matplotlib.



\### Run the Project



Create and activate a virtual environment, then install the dependencies:



```powershell

python -m venv .venv

.\\.venv\\Scripts\\Activate.ps1

pip install -r requirements/requirements.txt

python app.py

```



Open http://127.0.0.1:5000/ in your browser.



\### Purpose

This project explores network attack detection, adversarial robustness and explainable machine learning for defensive cybersecurity research.
